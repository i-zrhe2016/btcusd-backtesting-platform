# 服务边界

## Nginx Web 入口

Nginx 是唯一公网入口，不承载业务逻辑。

- `/`：Vue 构建产物，未知前端路径回退到 `index.html`。
- `/api/market/*`：转发到 `market-data:8081`。
- `/api/backtests*`、`/api/configs*`：转发到 `backtest:8082`。
- `/healthz`：只表示 Nginx 自身可用，不代表依赖服务健康。
- HTTP 永久重定向到 HTTPS；生产证书由宿主机证书工具签发并只读挂载。

## Market Data Service

行情服务只负责不可变历史数据的读取与确定性计算：

- 启动时验证并加载一个 BTCUSD `1m` Parquet 数据集。
- 按 UTC 边界筛选、排序和聚合 OHLCV。
- 计算 `stoch_btc_v9_k5_optimized` 的前三组 K/D。
- 返回数据集元数据和市场快照。

它不访问 PostgreSQL，不保存用户状态，不执行策略，也不接受行情文件上传。更换行情文件通过运维流程完成，重启服务后原子切换。

## Backtest Service

回测服务只负责策略生命周期：

- 校验策略、时间范围、初始资金和手续费。
- 创建并维护 `running/completed/failed` 回测状态。
- 调用行情服务获取对齐的行情和指标。
- 执行确定性策略、计算指标并保存结果。
- 管理属于当前用户的策略配置与回测历史。

它不直接读取 Parquet，也不自行重复实现指标。行情服务不可用时，回测必须失败并保留可诊断错误，不能改用缓存数据静默完成。

## PostgreSQL

PostgreSQL 由回测服务拥有。其他服务不得直接读取其表。M1 使用固定本地访客用户 `00000000-0000-0000-0000-000000000001`，数据模型保留 `user_id` 以便后续引入认证而不重写历史记录。

## 通信规则

- 浏览器到 Nginx：HTTPS + JSON。
- Nginx 到 Axum：Compose 私网 HTTP。
- 回测到行情：Compose 私网 HTTP，请求超时默认 30 秒。
- 回测到 PostgreSQL：连接池，最大连接数默认 10。
- 时间统一使用 Unix UTC 秒；金额计算 M1 使用 `f64`，结果注明这是研究工具而非会计账本。
- API 错误统一返回 JSON，不向浏览器泄露数据库连接信息或内部堆栈。

## 扩展规则

只有出现独立数据所有权或独立扩缩容需求时才增加服务。M2 的回放会话、绘图和标记统一进入新的 `replay` 服务；不会塞入行情服务。认证在需要多用户联网使用时作为独立能力引入，不在 M1 预先建设。
