# Vue Web 应用

## 职责

前端使用 Vue 3 Composition API、TypeScript 和 Vite。它负责复盘项目管理、K 线回放、回测表单、结果摘要和历史列表，不在浏览器计算聚合或回测信号。

## 页面结构

单页工作台采用三个明确视图，避免把建项、复盘和回测选项挤在同一个页面：

1. `项目` 视图：创建复盘项目、设定品种、周期、UTC 回测时间和播放速度，并列出已保存项目。
2. `复盘` 视图：打开当前项目后进入应用视口级全屏 K 线回放，只保留必要播放控制、进度、当前 K 线 OHLC 信息和返回项目库入口。
3. `回测` 视图：独立承载策略参数、运行按钮、结果摘要和历史列表。

创建新项目或选择已有项目后直接进入 `复盘` 视图。复盘页的 K 线区域必须占满除顶部导航外的剩余应用视口；播放控制使用浮层呈现，不压缩图表高度。页面不得产生横向滚动。

复盘项目草稿和已保存项目保存在浏览器 `localStorage`，刷新后保持状态；行情与回测结果仍以服务端 API 为准。

## 图表约定

- K 线同时使用实体形态和涨跌颜色，不能只依赖红绿表达方向。
- 回放时按游标只显示已播放的 K 线，暂停后仍保留当前游标。
- 默认最多渲染 500 根，接口硬上限 5,000 根；超过可视密度时只请求或显示选定范围。
- 复盘图表只显示 K 线，不显示指标组、副图或 Stoch 图例。
- 底部浮层始终展示当前游标 K 线的 OHLCV 读数，作为无 Canvas 读数替代。
- 时间轴、表格和表单一律标记 UTC。

## 状态管理

不引入全局状态库。页面使用组合式函数分别管理：

- `replay`：项目、当前项目、快照、播放游标、播放状态和速度。
- `backtests`：表单、提交状态、当前结果和历史记录。
- `health`：元数据、加载状态和错误提示。

复盘项目、当前项目和最后选中的视图保存在浏览器本地；策略表单草稿保存在浏览器本地；已保存配置和回测结果以服务端为准。

## 交互与可访问性

- 所有输入使用可见 `label`，错误显示在对应字段附近。
- 异步提交期间禁用按钮并显示明确进度；失败信息包含原因和重试操作。
- 所有按钮可通过键盘操作，焦点环清晰；触控目标至少 `44×44px`。
- 正文对比度至少 `4.5:1`，数据线和控件边界至少 `3:1`。
- 遵循 `prefers-reduced-motion`，不使用阻塞式或纯装饰动画。
- 页面提供跳到主要内容的链接，标题层级连续，状态更新使用礼貌型 live region。

## API 访问

浏览器只使用同源相对路径 `/api/...`，不感知容器名或内部端口。前端不得持有 PostgreSQL、行情服务或回测服务凭据。
