# Vue Web 应用

## 职责

前端使用 Vue 3 Composition API、TypeScript 和 Vite。它负责复盘项目管理、K 线回放和手动 Buy/Sell 交易记录，不在浏览器计算聚合或交易信号。

## 页面结构

单页工作台采用两个明确视图，避免把建项和复盘操作挤在同一个页面：

1. `项目` 视图：创建复盘项目、设定品种、周期、UTC 复盘时间范围和播放速度，并列出已保存项目。
2. `复盘` 视图：打开当前项目后进入应用视口级全屏 K 线窗口，提供播放控制、周期切换、进度、当前 K 线 OHLCV、Buy/Sell、持仓、盈亏和最近成交。

创建新项目或选择已有项目后直接进入 `复盘` 视图。复盘页的 K 线区域必须占满除顶部导航外的剩余应用视口；项目标题和时间范围放在底部控制台摘要中，不能遮挡图表主体。底部控制台使用浮层呈现，可折叠为项目摘要、周期、播放按钮和状态，不压缩图表高度。页面不得产生横向滚动。

复盘项目草稿、已保存项目和手动交易记录保存在浏览器 `localStorage`，刷新后保持状态；行情数据仍以服务端 API 为准。

## 图表约定

- K 线使用语义填充色：纯黑色背景上，上涨为绿色实心实体，下跌为红色实心实体，并保留文字/位置等辅助信息，不只依赖颜色表达方向。
- 图表绘图区使用纯黑色背景，坐标轴、蜡烛和交易标记使用高对比浅色；复盘窗口不显示网格线或贯穿全图的最新价参考线。
- 回放时按游标只显示已播放的 K 线，暂停后仍保留当前游标。
- 复盘页支持切换周期；切换后以当前 K 线时间戳为锚点重新加载同一项目时间范围内的新周期 K 线，保留复盘进度并清空旧周期下的手动交易标记。
- 每次请求最多 240 根，接口硬上限 5,000 根；超过当前窗口时通过按需加载继续追加。
- 复盘图表只显示 K 线和手动交易标记，不显示副图或其他计算曲线。
- 底部浮层始终展示当前游标 K 线的 OHLCV 读数，作为无 Canvas 读数替代。
- 时间轴和表单一律标记 UTC。

## 状态管理

不引入全局状态库。页面使用组合式函数分别管理：

- `replay`：项目、当前项目、快照、播放游标、播放状态和速度。
- `trades`：当前项目的手动交易、持仓、已实现盈亏、浮动盈亏和最近成交。
- `health`：元数据、加载状态和错误提示。

复盘项目、当前项目、最后选中的视图和手动交易记录保存在浏览器本地。

## 交互与可访问性

- 所有输入使用可见 `label`，错误显示在对应字段附近。
- 异步提交期间禁用按钮并显示明确进度；失败信息包含原因和重试操作。
- 所有按钮可通过键盘操作，焦点环清晰；触控目标至少 `44×44px`。
- 正文对比度至少 `4.5:1`，数据线和控件边界至少 `3:1`。
- 遵循 `prefers-reduced-motion`，不使用阻塞式或纯装饰动画。
- 页面提供跳到主要内容的链接，标题层级连续，状态更新使用礼貌型 live region。

## API 访问

浏览器只使用同源相对路径 `/api/...`，不感知容器名或内部端口。前端不得持有 PostgreSQL、行情服务或其他服务凭据。

## K 线按需加载

复盘项目的时间范围可以大于单次浏览窗口。页面首次只请求最多 240 根 K 线，并在控制台显示当前已加载数量；用户点击“加载更多 K 线”时继续请求后续窗口。播放到当前窗口末尾会自动触发同样的加载动作，加载失败时保留已显示的 K 线并提供重试按钮。

切换周期时，页面保存当前游标 K 线的 UTC 时间戳，在新周期中定位到该时间点之前最近的一根 K 线；首个新周期窗口围绕该时间点加载，因此不会把进度重置到项目开头，也不会预加载完整项目范围。

行情数据刷新后，如果浏览器保存的项目时间范围超出服务端当前覆盖范围，页面会将该项目调整到可用范围，避免旧的 `localStorage` 项目导致空图。
